# Homo Fictor Edições Independentes

Fonte versionada do site institucional da Homo Fictor.

## Estado da migração
- Site público atual permanece inalterado durante a migração.
- Esta pasta contém uma reconstrução versionável baseada na versão 8 do projeto Homo Fictor e no conteúdo público de homofictor.com.br.
- A página de serviços já incorpora a política de IA com supervisão humana e a nova tabela de preços aprovada em setembro de 2026.

## Publicação
Projeto estático compatível com Vercel. Configurar o Root Directory como `homo-fictor-site` ao vinculá-lo a um projeto Vercel.
