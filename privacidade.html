Privacidade e uso de dados

Esta página explica, em linguagem direta, quais informações são utilizadas para operar e melhorar o site e o Simulador Empresarial da Reforma Tributária.

Métricas de uso

O site registra eventos operacionais para sabermos, por exemplo, quantas vezes o simulador foi aberto, se a consulta de CNPJ funcionou, se documentos foram selecionados, quais etapas foram alcançadas e quantos diagnósticos foram gerados.

Esses eventos não recebem nome, e-mail, telefone, CPF, CNPJ nem conteúdo dos documentos. As métricas servem para medir uso, identificar falhas e melhorar o fluxo da ferramenta.

CNPJ e consulta cadastral

Quando o usuário solicita a consulta de um CNPJ, o número é usado para consultar a base pública integrada ao simulador. O CNPJ não é incluído nos eventos de métricas de uso descritos acima.

Documentos enviados ao simulador

Na versão atual, PDF com texto pesquisável, CSV, XLS e XLSX são lidos no próprio navegador. O conteúdo desses arquivos não é enviado pelo módulo de métricas e não é encaminhado a uma API de inteligência artificial para interpretação documental.

Dados salvos no navegador

O simulador pode manter algumas premissas no armazenamento local do navegador para permitir continuidade da análise. O comando Limpar ou Refazer simulação permite iniciar um novo caso.

Contato opcional

Ao final do diagnóstico, o usuário pode informar nome, e-mail, WhatsApp, empresa e perfil profissional para receber atualizações. Esses dados permanecem no navegador até que o usuário clique em enviar. Quando a integração automática estiver ativa, o contato é encaminhado pelo próprio site para uma planilha privada no Google Sheets. Se a integração estiver temporariamente indisponível, o sistema pode oferecer o envio por e-mail como contingência.

O fornecimento do contato é opcional e não condiciona o acesso ao diagnóstico.

Finalidade e solicitações

Os dados enviados voluntariamente pelo formulário ou por e-mail são utilizados para responder ao contato e, quando autorizado, enviar informações relacionadas ao livro, ao site, ao simulador e à Reforma Tributária. Solicitações de correção, interrupção de comunicações ou exclusão de dados de contato podem ser enviadas para homofictor@hotmail.com.
